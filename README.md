# DharoharSetu (धरोहर सेतु) - AI Cultural Heritage & Hidden Utsav Radar
### Smart India Hackathon (SIH) Prototype

## Quick Start Guide

### 1. Requirements
- Python 3.10+
- FastAPI, Uvicorn, Requests (Already configured in your Python environment)

### 2. Run the Application
Open PowerShell in this directory:
```powershell
$env:PYTHONUTF8=1
python -m uvicorn main:app --host 127.0.0.1 --port 8000 --reload
```

### 3. Open in Browser
Visit: [http://127.0.0.1:8000](http://127.0.0.1:8000)

## Features Overview
- **Royal Cultural Theme**: Terracotta, temple gold, mandala motifs, and jaali styling.
- **AI Geolocation & Cultural Zone Mapping**: Auto-identifies current state & cultural belt.
- **Dual Range Radar**: 50km, 100km, or Entire State discovery.
- **Hidden Utsav Radar**: 1–10 day alert for hyper-local village melas and tribal rituals.
- **AI Vernacular Storyteller**: Hindi & English folklore narration with voice playback.
- **Crowdsource Living Heritage**: Submit village traditions to the map radar.
